### Консольное меню (CLI) 
cli.py нужен для вывода и ввода меню, отвечает за взаимодействие с польхователем.                   
**CLI (Command Line Interface)** — интерфейс, работающий в текстовом режиме с пошаговыми подсказками.                   

**Основной цикл работы:**
1. Показать меню
2. Получить выбор пользователя
3. Выполнить действие
4. Повторить до команды выхода

**Главное меню приложения:**
* Добавить студента
* Список всех студентов
* Найти студента (подменю: по фамилии, по имени, по курсу)
* Удалить студента по номеру
* Сортировать (подменю: по фамилии, по имени, по курсу, по GPA)
* Выход

### Обработка ошибок и собственные исключения
Исключения (Exceptions) — механизм обработки ошибок, позволяющий отделить логику от обработки ошибочных ситуаций. (т.е. событие, которое нарушает нормальный поток выполнения программы. Собственные исключения создаются для специфических ошибок предметной области)

`OutOfRangeException` значение вне допустимого диапазона (например, индекс при удалении)                    

`NotFoundException`	объект не найден в коллекции (при поиске по фамилии, имени, курсу)                  

`NotCorrectData` некорректный ввод данных (буквы вместо числа, пустые строки)               

### Сохранение и загрузка данных (JSON)
**JSON (JavaScript Object Notation)** — текстовый формат обмена данными, удобный для хранения структур данных.                  

Приложение автоматически:               
* Загружает данные при запуске из файла students.json
* Сохраняет данные при выходе из программы
* Создаёт файл автоматически, если он не существует

### Файл main.py — точка входа              
Содержит точку входа в приложение. При запуске создаёт экземпляр класса UserInterface и вызывает его метод run().               

### Файл app.py — бизнес-логика
Содержит класс StudentApp, который управляет коллекцией студентов:
* Добавление одного или нескольких студентов
* Поиск по фамилии, имени, курсу
* Удаление по индексу
* Сортировка коллекции по различным критериям
* Сохранение коллекции в JSON-файл

### Файл models.py — модели данных
Содержит два основных класса:

* `TypeCollection[T]` — обобщённая коллекция с методами `add()`, `remove()`, `find()`, `filter()`, `map()`, а также магическими методами `__len__()`, `__iter__()`, `__getitem__()`

* `Student` — класс студента с валидацией данных, свойствами (`@property`), бизнес-методами (`to_next_course()`, `to_collect_money()`), методами для протоколов (`display()`, `score()`)

### Файл storage.py — работа с файлами
Содержит две функции:
* save() — сохраняет коллекцию студентов в JSON-файл
1) Создаём пустой список data = [] — сюда будем складывать словари.
2) Перебираем всех студентов в коллекции:
    Для каждого студента создаём словарь, где:
    * Ключ — название поля (строка)
    * Значение — атрибут студента
3) Открываем файл для записи:
    * "w" — режим записи (write)
    * encoding="utf-8" — для поддержки русских букв
4) Превращаем список в JSON и сохраняем:
    * json.dump() — записывает JSON в файл
    * ensure_ascii=False — не превращать русские буквы в коды
    * indent=2 — красивые отступы (читаемый вид)

* load() — загружает данные из JSON-файла
1) Пытаемся открыть файл для чтения:
    * "r" — режим чтения (read)
    * Если файла нет — ловим ошибку и возвращаем пустой список
2) Загружаем данные из файла:
    * json.load() — читает JSON и превращает его в список словарей
    * Возвращаем полученный список

`BASE_DIR = Path(__file__).resolve().parents[1]`
`__file__`	Получает путь к текущему файлу                  
`Path(__file__)`	Превращает строку пути в специальный объект Path                    
`.resolve()`	Превращает относительный путь в абсолютный (полный) 
.parents[1]	Поднимается на 1 уровень вверх по папкам
